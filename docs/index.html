KitchanaClipper

KitchanaClipper is a personal tool that produces videos for YouTube channels run by its owner: short facts and stories, news recaps, game highlights made with creators' permission, and long ambience videos. Each video is reviewed and approved by a person before it is uploaded to the owner's own YouTube channels using YouTube API Services.

It is not a public service. Nobody else signs in to it, and it does not access anyone else's YouTube data.

What it does with YouTube

  • Uploads the owner's approved videos to the owner's channels.
  • Sets each video's thumbnail, title, description and publish time.
  • Reads the owner's channel name and each upload's processing status to confirm it worked.
